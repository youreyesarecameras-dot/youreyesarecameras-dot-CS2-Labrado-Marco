# Electricity Calculator
## Description
This program calculates the electricity bill cost, along with input vaiidation
## Version 1 - Original code without input validation
- Input: Accepts a customer's name, rate, and two readings.
- Process: Calculates and displays the consumtion.
- Output: Electricity consumption, and total cost.
- Does not include input validation
## Version 2 - Original code with input validation
- Input: Accepts a customer's name, rate, and two readings.
- Process: Calculates and displays the consumtion.
- Output: Electricity consumption, and total cost.
- Does include input validation for name and the two readings
